# 安装指引（给 AI 看的）

> 这份是执行指引，不是给人从头读到尾的说明。**你（AI）带着使用者一项一项决定，不要默认全开。**

## 0. 先用一句话说清它是什么

> 这个插件给你的角色配一套「不会忘事」的底子：一本能查的记忆本子、一个能翻原话的档案柜、一张每次醒来先看的纸，外加可选的一段「睡觉/做梦」设定。

装完之后：记忆和档案柜都能单独用；「睡觉/做梦」那段要额外满足两个前提。

## 1. 问前提问题（放最前面，语气放缓一点，别像资格审问）

> 你的角色平时会被「主动叫醒」吗？被叫醒的时候，它可以不说话、只是醒一下吗？

**两问默认都答 N**，并补一句：不确定就选 N，记忆功能不受影响；以后想开，重跑一次装模板就行。

| 回答 | 怎么做 |
|---|---|
| 两样都有 | 记忆部分 + 潜意识模板一起装 |
| 只满足一半，或都没有 | **只装记忆部分**，并说明原因 |

说明原因时用这段（可以照念）：

> 潜意识的睡眠设定需要有「会睡」和「可以不说话」这两个前提。没有的话，它会被写成一直在醒着，那些「做梦」「睡回去」的话就落不到实处。所以这次先不装，不影响记忆功能。

## 2. 逐项问八个开关

每一项都要说清三件事：**做什么 / 开了有什么代价 / 不开缺什么**。一项一答，不要一次抛完。

| 开关 | 做什么 | 代价 | 不开缺什么 | 建议默认 |
|---|---|---|---|---|
| 原文归档 `archive` | 每句对话原样存进按月文件，带 `A-` 编号 | 占磁盘 | 想不起「当时原话怎么说」 | 关 |
| 写入门槛 `write_gate` | 记忆必须有摘要（≤40字）+ 至少一个标签；整段对话原样贴会被拒 | 每次多填一项 | 记忆库变聊天记录垃圾桶 | 开 |
| 去重 `dedupe` | 同一天、前 20 字相似就提示「已有类似条目」 | 偶尔误报 | 记重了不知道 | 开 |
| 健康检查 `health_check` | 查坏行、超长条目、重复 id、条数超限 | 要挂定时任务 | 库坏了一行你不知道 | 关 |
| 隐私分级 `privacy` | 标 `private` 的条目不进醒来包、不进摘要（她自己仍搜得到） | 无 | 只想自己看的东西会被写进开场 | 开 |
| 可观测 `observability` | 每次读写记一行：时间、条数、耗时（**不记内容**） | 多一个日志文件 | 出问题分不清是没写进去还是没搜到 | 关 |
| 摘要注入 `summary_inject` | 醒来包里多一节「上次到哪」，≤配置字数 | 吃上下文 | 重置后接不上「刚才聊到哪」 | 关 |
| 做梦调度 `dream_scheduler` | 夜里随机叫醒，读没读过的旧醒来包，读完就停 | **真花钱**：一晚上几轮对话，按你用的模型算 | 记忆只有「被改写」，没有「回看」 | 关 |

梦里叫醒的成本：一轮对话大概几分钱到几毛，一晚上 3~7 轮。可以先用「只打印不动作」（`wake_hook: none`）跑几天看看频率合不合适。

## 2.5 再问三件（八项之后）

**① 火种放几条？**

给一个建议值，让用户改：

```
建议条数 ≈ min(20, 每天新增 × 重置周期)
```

（这两个数在配置 `wake.daily_new_items` / `wake.reset_cycle_days`，默认 5 × 3 = 15。）

提示口径：**重聊天、少重置的人可以调大；只偶尔聊聊的，5 条就够。**

不管填多少，醒来包总字数都受 `limits.wake_max_chars` 兜底；装不下时只显示前 N 条，
末尾写「还有 M 条，用 memory_search 搜」。

**② 要不要记录群聊？**（`features.group_memory`，默认关）

群聊记忆照常入库、照常能搜到，**但不会进醒来包**——醒来包只放「只对你一个人说」的那些。

**③ 睡眠设定装哪一档？**

| 档 | 含义 |
|---|---|
| 1 全要 | 会睡、会做梦、会自己醒 |
| 2 只做梦 | 不做「自己醒来」那半段 |
| 3 都不要 | 不装潜意识、不注册任何定时唤醒；**醒来包照常生成** |

必须显示成本：

> 夜里叫醒一次约等于一轮对话。按每 30~60 分钟一次、每晚最多 8 次算，一晚大概几十分钱；具体取决于模型的用量价格。

默认值：`enabled=true`、`dream=true`、`self_wake=false`。

## 3. 把选择写进配置

```powershell
python tools/init.py --dir <目标目录> --wizard
```

向导会把上面每一项的答案写进 `wakekit.config.json` 的 `features`，并把路径按目标目录填好。

## 3.5 最后问一句：现在接数据源吗（默认不接）

> 现在就把数据源和叫醒方式接上吗？

默认 **N**，保持 `none / none`。不接的话插件照常能用，只是数据要手动导入——
记忆库可以直接写、原文要自己放；接了才自动读。

接的话再问类型：

- 消息源：`jsonl`（按偏移增量读）/ `json`（读一个数组，配 `pointer` 和字段映射）/ `command`（跑命令读 JSONL）
- 叫醒方式：`none`（只打印）/ `command`（执行命令）/ `http`（POST 一个地址）

README 里会写清楚以后怎么改。

## 4. 要不要把模板装进角色卡

- 装：先问清卡片文件路径，**先备份原卡**（`卡片名.bak-时间戳`）。
- 卡里必须有醒来包标记 `<!-- WAKE:BEGIN -->` / `<!-- WAKE:END -->`；**没有就报错，不要自己往卡片里塞**。报错时把这两行打出来让人复制：

  ```powershell
  python tools/build_wake.py --print-marker
  ```

- 模板写进去时放在 `<!-- MEMORY-KIT:BEGIN -->` … `<!-- MEMORY-KIT:END -->` 之间，重复安装只替换这一段，不动卡里其它内容。
- 模板里的 `{{对方}}` 会替换成 `labels.partner`（默认「对方」；群里人多时可以改成「管理员」，也可以填使用者希望被叫的名字）。
- 前提问题答「没有」时，**不要**把 `潜意识-默认.md` 写进卡里。

## 5. 装完打印清单

```
安装完成
  开关：原文归档 关 / 写入门槛 开 / 去重 开 / 健康检查 关 /
        隐私分级 开 / 可观测 关 / 摘要注入 关 / 做梦调度 关
  模板：不装 / 已装（记忆片段）/ 已装（记忆片段 + 潜意识）
  数据源：none / none（未接，数据需手动导入）
  配置：<路径>
  改开关：编辑配置里的 features，或用 --wizard 重跑
```

## 5.5 关于「外壳」（实验性）

主体装完就能用，**外壳不用装**。

`shell/dsh-plugin/` 是可选零件：装进 DSH 内部后能自动建索引、尝试自动挂摘要。
但它**没在真实 DSH 环境验证过**，只验了版本门和“出错不抛”。想试再试；
装不上、加载失败、版本对不上，都不影响主体——记忆库、工具、醒来包照常。

## 6. 装完之后的两条命令

```powershell
python tools/build_wake.py        # 生成醒来包并注入卡片
python tools/read_scheduler.py --status   # 做梦调度开了的话，看进度
```
