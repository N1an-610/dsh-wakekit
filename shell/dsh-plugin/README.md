# wakekit 外壳（实验性）

**没在真实 DSH 环境里验证过。** 只验证了三件事：导出形状对、版本门有效、出错不抛异常。

装进去会做两件事：
1. 定时跑 `archive_chat.py` 自动建索引（默认 30 分钟，可用 `shell.interval_minutes` 改）
2. 尝试把「上次到哪」挂进系统提示——DSH 各版本接口不同，探测不到就跳过并打一行日志

版本门：支持 `>=0.2.0 <0.3.0`。版本读不到默认拒绝加载；
确要跳过检查设 `WAKEKIT_SHELL_ALLOW_UNKNOWN=1`。

**它坏了不影响主体**：记忆库、七个工具、醒来包都不依赖它。
