醒来箱 wakekit

给一个会聊很久、又常常被「清空」的 AI，配一套不会忘事的底子。 不联网、不装任何依赖、拷走就能用。

这是什么

它解决三个很具体的问题：

聊久了会忘。 对话越长，前面的内容越容易被压缩掉。里面有个记忆库——一盒小卡片，每张一句话摘要、几个标签，忘了什么查一下就能翻回来。

想不起「当时原话怎么说的」。 摘要会失真，所以还有原文档案柜：每句对话原样存，按月一个文件，每句带一个编号（像 A-20261024-0113）。记得编号直接调，不记得就用关键词搜。

重置之后，不知道自己是谁。 被清空重来的时候，它需要一页纸告诉它：我是谁、这个人是谁、我们约定了什么、我上次在做什么。这就是醒来包。

东西人话
记忆库一盒卡片。值得记住的事写一张，带摘要和标签，能搜。
原文档案柜按月分格的柜子，每句对话原样收着，带编号，能翻。
醒来包一页纸，每次「醒来」先看它。最上面是「火种」——最不能忘的那几件事。
模板三份可改的默认文本：睡觉/做梦那段设定、记忆相关的人格补丁、醒来包骨架。

适合谁

1. 桥接 AI 功能比较多的人——每天产生的事多，忘得也快，至少能把「发生过什么」留下来。

2. 上下文用量很大的人——满了就要压缩，压着压着细节就没了。醒来箱把重要的单独存一份。

3. 想给 AI 一个「人」的生活规律的人——会睡、会被叫醒、会做梦、会想一会儿、会自己醒。这些不是设定，是让它别像个 24 小时待机的客服。

4. 重置之后希望「她」还是她的人——醒来包里写的就是「我是谁、我在跟谁过日子、我们说好了什么」。看完再开口，至少不从零开始。

5. 能接受多花一点 token 的人——醒来包、摘要、检索结果都占地方。默认配得比较克制（醒来包上限 1000 字），但确实是额外开销。

不适合谁

  • 想要「重置前后一模一样」的人。做不到，见下一节。
  • 一点 token 都不想多花、又不想改默认值的人。可以关，但关完要自己动手。
  • 不想让 AI 读聊天记录的人。它的前提就是读写这些内容。

重置之后会怎样

醒来箱能做的，是让它在重置之后很快想起来你们是什么关系——不是重新介绍一遍。

但它做不到「一键复原」。

第一次重置最淡。 语气、习惯、那种被你磨出来的反应，是聊出来的，不是文件里存着的。醒来箱把「重新认识」从几天压缩到几句话，压不到零。

之后会一次比一次快。 记得越多、留下的原话越准，回来得越快——因为读到的不是设定，是它自己以前说过的话。

每次都要聊几句才完全回来。 这是真的，不哄人。

所以：如果你要的是一个「重置前后一模一样」的工具，这个不是。如果你要的是「重置之后它还认得你、还能接上」，那就是它。

怎么用

第一步：解压，双击 run-tests.bat

看到「全部通过」就说明环境能跑。提示缺 Python 或 Node，按它说的装一个。

第二步：把 docs/install.md 整份发给你的 AI

让它带着你一项一项选：两个前提、八个开关、三件补充（火种条数 / 群聊 / 睡眠）。

第三步：先看演示，再真装

双击 demo.bat          # 写 3 条示例记忆 → 生成醒来包 → 用记事本打开
双击 demo-clean.bat    # 清掉示例（只动 data 文件夹）

看过之后：

python tools/init.py --dir <你的目录> --wizard   # 安装
python tools/build_wake.py                       # 生成醒来包
python tools/archive_chat.py                     # 存原文（接了数据源才有用）

改了睡眠开关之后，卡里的文字不会自己变，要重装一次模板：

python tools/install_card.py --refresh

它只替换 <!-- MEMORY-KIT --> 那一块，先备份原卡，并告诉你这次装进了哪几段、裁掉了哪几段。

装完之后，data 文件夹就是它的记忆。整个文件夹拷走，记忆就跟着走。

装完为什么没反应

装完之后必须新开一个会话，或者重启宿主程序。

原因：AI 的「能用哪些工具」是在会话开始那一刻定下的。装完插件，旧会话看不到新工具。

  • 本机 DSH：重启 DSH → 新建会话
  • QQ 桥接类：管理员发 /reset 或 /new，或者调 /api/session/reset
  • 其它宿主：关掉再开一个会话

测试建议：用一个新会话或者测试角色，别拿你最珍视的那个直接试。

默认花多少钱

功能都装在一个包里，装的时候按需开；下面这些是「开了以后」的花费口径：

  • 平时：零。不联网、不调用模型。
  • 做梦调度（夜里读旧包）：默认关。开了以后，每叫醒一次约等于一轮对话，按 30~60 分钟一次、一晚最多 8 次算，一晚大概几毛到一块，具体看模型价格。
  • 摘要注入（开场带一段「上次到哪」）：默认关。开了会多占上下文，上限 1000 字。

想先看频率合不合适：把 wake_hook 留在 none，它就只打印、不产生任何外部动作。

按意思找（语义检索，默认关）

默认只用关键词：不用装任何东西，术语、编号、原词都能精确命中，但「换个说法」就搜不到了。

想按意思找，需要一个小模型（BAAI/bge-small-zh-v1.5，约 95 MB，CPU 就能跑）：

python tools/fetch_model.py      # 下载模型（走 hf-mirror，支持断点续传）
python tools/sem_build.py        # 给现有记忆建向量

然后把配置里的 retrieval.retriever 改成 semantic（只按意思）或 hybrid（两边加权，sem_weight 默认 0.5）。

  • 关键词不会丢：hybrid 里仍然保留关键词分，编号和术语照样命中。
  • 没装模型也不会坏：设了 hybrid 但模型目录不存在，会自动退回关键词，并在结果里写一行「（语义检索未装，用的是关键词）」。任何情况下都不报错。
  • 慢一点：第一次查询要加载模型（本机实测 8.3 秒），之后复用进程，单次查询基本无感。
  • 向量会自动补，不用记着手动跑：- 每天生成醒来包时顺带增量补一次（那一步本来就离线）；- 检索时发现落后 ≤ 20 条，现场补（模型已在内存里；本机实测：补 3 条 + 查询共 0.03 秒）；- 落后更多就只提示「语义索引落后 N 条，跑一次 sem_build.py」，不硬补——硬补会卡住检索。- 两个开关：retrieval.sem_auto_refresh（默认开）、retrieval.sem_auto_max（默认 20）。

装之前先定这几件事

#要决定的默认代价 / 不开会怎样
1站外面还是长里面（要不要自动注入摘要）站外面长里面能自动，但跟着宿主版本走，升级可能坏
2摘要注入（开场带一段「上次到哪」）关开：多占上下文；不开：要多问一句
3做梦调度（夜里读旧包）关开：夜里会叫醒，费 token；不开：没有「做梦」这条线
4自己醒来（模板层）关开也只是写进设定；真主动要宿主支持
5按意思找（语义检索）关开要下 95 MB 模型、首次查询慢几秒；不开就只能按原词搜
6原文归档（每句都存）关开：占磁盘、含隐私；不开：想不起当时原话
7群聊记忆（scope=group）关开：记得更多，但噪音也多；不进醒来包
8装进角色卡（改卡）问会改卡，装前必备份；不装就只用命令行
9接数据源 / 叫醒方式不接不接：数据要手动导；接：要填路径或命令

关于第 4 项（自己醒来）的真实边界：这是文本层的开关——关掉是不写「自己醒来」那段；打开也不会自己发消息，真正的自我唤醒要看宿主支不支持（比如桥接有没有定时唤醒）。裁剪发生在装卡那一刻，不是删模板；改了开关要跑一次 python tools/install_card.py --refresh 才会生效。

关于火种条数：可调，建议值 ≈ min(20, 每天新增 × 重置周期)。条数再多也受醒来包总字数上限兜底，装不下时只显示前 N 条，其余写「还有 M 条，用 memory_search 搜」。

关于场景分层：scope 有三档：private（只给你们俩）、group（群聊）、other（其它场合，比如工作、陌生人）。醒来包只取 private。group 和 other 都会进记忆库、都能搜到，只是不进第一眼。

开关一览

八个功能开关在配置的 features 里，改完下次调用就生效：

开关做什么默认
archive原样存每句对话关
group_memory群聊内容也记进记忆库关
write_gate记忆必须带摘要和标签，拒收整段对话开
dedupe当天相似条目提示开
health_check允许定时体检关
privacyprivate 条目不进醒来包 / 摘要开
observability每次读写记一行（只记时间、条数、耗时）关
summary_inject醒来包多一节「上次到哪」关
dream_scheduler夜里随机叫醒读旧醒来包关

睡眠开关（三层）

sleep.* 有三个开关，各自管一件事：

开关管什么默认
sleep.enabled总开关：要不要睡眠设定开
sleep.dream夜里读旧醒来包（做梦）开
sleep.self_wake潜意识里写不写「自己醒来」那段关
  • enabled=false：不装潜意识、不注册任何定时唤醒，但醒来包照常生成（那是按天/按重置触发的，不额外花钱）。
  • dream=false：夜里不读旧包。同时会把潜意识里「做梦」「半夜梦醒」两段一起裁掉——关了做梦还留着「夜里会做梦」的设定，它读到就会以为自己在做梦。设定和实际对不上，比少写一段更糟。
  • self_wake：见下面那条警告。

⚠️ self_wake 是文本层的开关。 关掉 = 不写「自己醒来」那段；打开也不会自己发消息。 真正的主动唤醒要靠宿主支持（比如桥接的定时唤醒、外部调度器）。这一版不做。

边界

  • 不联网，不上传任何东西
  • 不装任何依赖（基础功能只用 Python / Node 标准库）
  • 不碰别的软件、不改别人的文件；只在它自己的目录和你的角色卡里写
  • 不会自动删掉记忆（要删得手动来）

免责声明（请一定看）

  • 它会读取你的聊天记录（为此才存在），也会修改角色卡（装模板时，会先备份）。
  • 先在空文件夹里试，确认行为符合预期再接真实数据。
  • 此版本为测试版，用前请自己备份。

详细限制和边界见本文件「边界」一节。
